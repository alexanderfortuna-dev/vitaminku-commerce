# Panduan 1 Halaman VitaminKu

## 1. Pelanggan
1. Buka vitaminku, cari produk, ketuk **Tambah ke Keranjang**.
2. Buka **Keranjang** → **Checkout**. Isi 3 hal: nama, nomor WhatsApp, alamat. Cabang terpilih otomatis dari tautan yang Anda terima.
3. Ketuk **Pesan**. WhatsApp terbuka ke admin cabang; ketuk **Kirim**.
4. Admin akan membalas untuk konfirmasi. Pantau status di halaman pesanan.
5. Ingin pesan lebih cepat lain kali? Ketuk **Simpan data saya**, masukkan email, ketuk tautan di email. Tanpa kata sandi. Belanja tanpa akun juga bisa.
Contoh: Budi pesan 2 botol whey protein lewat tautan Cabang Canggu → pesan masuk ke admin Canggu.

## 2. Tim Produk (tambah/ubah produk dari ponsel)
1. Masuk di `/admin/login`, buka **Tambah Cepat**.
2. Ketuk foto (kamera), isi nama, merek, kategori, harga, stok, berat → **Simpan** (jadi Draf, aman).
3. Lihat daftar centang. Merah = belum lengkap; ketuk **Perbaiki**. Hijau semua → **Tayangkan** (Manajer/Owner).
4. Buka **Antrian Kerja** tiap pagi: kerjakan produk tanpa foto/harga/berat, produk Hero paling atas.
Contoh: Produk "Vitamin C 500mg" tanpa foto → ketuk Perbaiki → tambah foto → hijau.
Catatan: harga pokok (HPP) tidak terlihat oleh Tim Produk.

## 3. Admin Cabang
1. Buka **Pesanan Masuk**. Kartu merah = belum dikonfirmasi lebih dari 10 menit.
2. Ketuk **Konfirmasi Pesanan** lalu **Kirim WhatsApp** (pesan sudah terisi) → ketuk Kirim di WhatsApp.
3. Lanjutkan tahap: Dikemas → Dikirim → Selesai. Tiap tahap ada tombol WhatsApp.
4. Salah pesanan? **Batal** (ada konfirmasi). Stok mengikuti otomatis.
5. Bagikan tautan/QR cabang dari **Tautan & QR** (Manajer).
Contoh: Pesanan whey protein masuk 14.02 → konfirmasi 14.05 → dikemas → kirim dengan resi, tempel resi di pesan WhatsApp.
